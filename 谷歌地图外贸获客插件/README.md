# Google Maps 海外客户自动抓取与联系方式提取插件

## 项目说明

这是一个可直接本地安装的 Chrome/Edge 插件，基于 Manifest V3 开发，运行时无需后端、无需数据库、不会上传数据。

插件可在 Google Maps 中按关键词、国家、城市批量抓取海外商家信息；当只输入项目关键词时，会自动轮询预设海外国家与城市，并进一步进入官网或社媒页面提取公开联系方式，最后导出为 CSV 或 Excel。

## 文件清单

- `manifest.json`
- `popup.html`
- `popup.js`
- `content.js`
- `background.js`
- `style.css`
- `README.md`

## 安装教程

1. 打开 Chrome 或 Edge 浏览器。
2. 进入扩展管理页：
   - Chrome：`chrome://extensions/`
   - Edge：`edge://extensions/`
3. 打开右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择当前项目文件夹。
6. 安装完成后，浏览器工具栏会出现插件图标。

## 使用教程

1. 先打开 Google Maps 页面，例如：
   - `https://www.google.com/maps`
2. 点击插件图标，打开插件面板。
3. 选择输入方式：
   - 只填关键词：自动轮询预设海外国家与城市
   - 填国家不填城市：自动轮询该国家下的预设城市
   - 同时填写国家 / 城市：按指定地区精确采集
4. 在关键词输入框填写关键词：
   - 单个关键词：`Restaurant`
   - 多个关键词：`Restaurant, Coffee Shop`
   - 留空关键词：自动使用内置 4 个关键词
5. 可选勾选“跳过已采集过的城市”，只要某个城市历史上采集过，后续重启或重新运行时都会直接跳过；未完成的城市会保留已有结果，下次继续采集而不是清空重来。
6. 点击“开始采集”。
7. 插件会自动执行以下动作：
   - 在 Google Maps 中搜索目标关键词
   - 根据输入条件自动切换国家与城市
   - 自动滚动列表加载更多商家
   - 自动进入商家详情页
   - 提取公司名称、地址、电话、官网、评分、营业时间、类别
   - 自动打开官网或社媒新标签页补采电话、邮箱、地址、采购相关信息
   - 自动从官网提炼 60 字内中文“业务介绍”
   - 自动关闭补采标签页
8. 采集过程中可再次点击“停止采集”中断任务。
9. 采集完成后，点击：
   - “导出 CSV” 导出 `.csv`
   - “导出 Excel” 导出 `.xls`

## 导出字段

导出结果包含以下字段：

1. 公司名称
2. 联系电话
3. 邮箱
4. 官网地址
5. 所在国家
6. 所在城市
7. 搜索关键词
8. 业务介绍
9. 社媒链接
10. 商家评分

## 注意事项

1. 插件只能在 Google Maps 页面启动。
2. Google Maps 页面结构会不定期调整，如果 Google 页面 DOM 结构变化，个别抓取选择器可能需要同步更新。
3. 官网和社媒信息提取依赖公开页面内容，若目标网站采用强登录限制、反爬机制或纯前端异步渲染，信息完整度可能下降。
4. 本插件仅抓取公开可见信息，请确保实际使用符合目标国家/地区的法律法规、平台条款和数据合规要求。

## 推荐操作方式

1. 项目初筛时优先使用“只填关键词”模式，让插件先自动跑海外预设国家和城市。
2. 深挖某个市场时，建议填写国家、不填城市，让插件自动轮询该国家下的多个城市。
3. 导出后用 Excel 进行二次筛选，例如按邮箱、电话、国家、城市去重。
