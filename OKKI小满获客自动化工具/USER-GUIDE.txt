OKKI 自动获客独立版使用指南

一、第一次使用

1. 先把 OKKI-Web-Portable.zip 解压到电脑上的任意文件夹。
2. 不要直接在压缩包里面运行。
3. 打开解压后的文件夹。
4. 双击 Start-Web.bat。
5. 第一次启动会自动检查并安装依赖，可能需要等待几分钟。
6. 浏览器会自动打开：
   http://127.0.0.1:8000

二、每台电脑独立运行

每台电脑都需要解压一份这个一键包，并在自己电脑上双击 Start-Web.bat。

每台电脑打开的地址都是：
http://127.0.0.1:8000

这个地址只代表当前这台电脑自己，所以不同电脑之间互不影响。

三、OKKI 账号配置

1. 第一次新建采集任务时，需要填写自己的 OKKI 账号和密码，或者填写 Cookie。
2. 提交后，当前电脑/当前浏览器会记住这套配置。
3. 后续再新建任务，会自动显示上次保存的 OKKI 配置。
4. 如果修改了账号、密码、Cookie 或智能贸易数据 URL，下一次会以修改后的配置为准。

四、新建采集任务

1. 填写产品名称或 HS 编码，二者至少填写一个。
2. 可填写采购商国家/地区，例如：美国、马来西亚。
3. 设置最低金额阈值和最大翻页数。
4. 点击提交任务。
5. 任务会在后台开始采集。

五、停止和继续采集

1. 正在运行的任务可以点击停止任务。
2. 已停止或失败的任务可以点击继续采集。
3. 相同条件的新任务会识别历史记录，并接着之前的历史继续采集。
4. 相同条件包括：产品名称、HS 编码、采购商国家/地区、最低金额阈值。

六、下载数据

1. 任务列表和任务详情页都有 Excel / HTML 下载按钮。
2. 不需要等任务全部结束，只要已有采集数据，就可以随时下载。
3. 点击下载时会弹出保存位置选择窗口。
4. 如果浏览器不支持选择保存位置，请在浏览器设置里开启“下载前询问每个文件的保存位置”。

七、本机数据保存位置

每台电脑的数据都保存在本机：
C:\Users\当前用户\AppData\Local\OKKI自动获客\web_data

这里包含任务记录、导出文件、历史状态和 Chrome 采集资料目录。

八、注意事项

1. 电脑需要安装 Python 3。
2. 电脑需要安装 Chrome 或 Edge。
3. 运行期间不要关闭 Start-Web.bat 的黑色窗口，关闭窗口会停止服务。
4. 如果 8000 端口被占用，启动脚本会尝试自动关闭旧的本机服务。
5. 每个人都应该在自己电脑上运行，不要共用别人电脑的 192.168.x.x:8000 地址。
